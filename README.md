# 🎮 لعبة إنسان حيوان نبات جماد بلاد

لعبة المتعة والذاكرة العربية الكلاسيكية، معاد تطويرها كلعبة ويب عصرية وتفاعلية باستخدام **Phaser 3** و **JavaScript** ومؤثرات صوتية حية عبر **Web Audio API**.

---

## ✨ المميزات الرئيسية

1. **عجلة الحروف التفاعلية (Phaser 3 Wheel)**:
   - عجلة دوارة بلون هادئ ومريح للعين وحروف كبيرة واضحة، تدور وتتباطأ بسلاسة مع نقرات صوتية تفاعلية لاختيار الحرف العربي عشوائياً.
   - تأثيرات جزيئات ضوئية ومفرقعات واحتفال عند توقف العجلة.

2. **الخصم الذكي (AI Opponent)**:
   - منافس إلكتروني يحاكي سرعة كتابة بشرية ويختار كلمات مناسبة حسب مستوى الصعوبة (سهل، متوسط، خبير).
   - شريط تقدم مباشر يوضح ما يكتبه الخصم في الوقت الفعلي.
   - إذا أكمل الخصم حقوله قبلك، يعلن "قِف! خَلّصت" ويمنحك 10 ثوانٍ كمهلة ذعر لإنهاء كلماتك!

3. **زر «قِف! خَلّصت»**:
   - بمجرد ملء الحقول يمكنك الضغط على زر «قِف! خَلّصت» الكبير، مع صافرة ممتعة ومكافأة +5 نقاط إضافية لمن يسبق بالضغط.

4. **قاموس عربي مدمج وذكي (Smart Dictionary)**:
   - يغطي كل حروف الهجاء العربية (28 حرفاً) لجميع التصنيفات: (إنسان، حيوان، نبات، جماد، بلاد، مهنة، أكلة).
   - معالجة تلقائية لأداة التعريف "الـ" وتوحيد الهمزات والألف والتنوين.
   - إمكانية مراجعة وتعديل النقاط يدوياً بعد كل جولة لقبول الكلمات المحلية أو اللهجات غير المدرجة في القاموس.

5. **مؤثرات صوتية حية (Web Audio API)**:
   - لا حاجة لملفات صوتية خارجية؛ نقرات دوران العجلة، نقرات المفاتيح، صافرة التوقف، وتناغم الفوز يتم توليدها برمجياً.

6. **غرف اللعب الجماعي بالدعوة (Multiplayer حتى 8 لاعبين)**:
   - إنشاء غرفة برمز كود قصير (مثل: `K7B2`) مع رابط دعوة مباشر وذكي وسريع الحفظ: `http://localhost:3000/join/K7B2`.
   - صالة انتظار (Lobby) تفاعلية تعرض مقاعد اللاعبين المنضمين (حتى 8 لاعبين كحد أقصى) مع تعيين المستضيف (Host).
   - جولات متزامنة بالكامل في تدوير العجلة، وزر «قِف! خَلّصت»، والتصويت المباشر على الإجابات عبر WebSockets.

7. **دعم كامل للغتين (العربية والإنجليزية - Bilingual)**:
   - زر تحويل فوري للغة في شريط الرأس: `🌐 English / العربية`.
   - تبديل تلقائي لعجلة الحروف: الحروف العربية (28 حرفاً) أو الحروف الإنجليزية (A-Z).
   - قواميس متكاملة للتصنيفات باللغتين العربية والإنجليزية.
   - دعم كامل لاتجاه الواجهة (RTL للعربية و LTR للإنجليزية) مع ترجمة فورية لكافة الشاشات والمحكمة وغرف اللعب الجماعي.

## 🌐 اقتراحات لأسماء الروابط والدومينات السهلة السريعة (Catchy Brand Names)
عند رفع اللعبة على الإنترنت، نوصي باختيار اسم قصير وسهل الحفظ من هذه الخيارات:
1. **`khalast.app`** (خَلّصت) ⭐ - أسهل اسم بالعامية والإنجليزية، ومطابق لاسم زر التحدي!
2. **`ensan.game`** - اسم كلاسيكي معبر فوراً عن اللعبة الشهيرة (إنسان).
3. **`stopword.io`** - اسم عالمي جذاب جداً ومفهوم لجميع اللاعبين حول العالم.

ومع نظام التوجيه الذكي في اللعبة، تصبح روابط دعوة الأصدقاء فائقة السهولة:
`khalast.app/join/K7B2`

افتح سطر الأوامر وشغل:
```bash

```
ثم افتح متصفحك على:
[http://localhost:3000](http://localhost:3000)

## 🏆 نظام النقاط

- **10 نقاط**: إجابة صحيحة وفريدة (لم يكتب الخصم نفس الكلمة).
- **5 نقاط**: إجابة صحيحة لكنها مكررة (نفس إجابة الخصم).
- **+5 نقاط إضافية**: للاعب الذي يضغط «قِف! خَلّصت» أولاً.
- **0 نقطة**: إجابة خاطئة أو حقل فارغ.

## 📱 النشر والتشغيل على الجوالات (Mobile Ready)

اللعبة الآن مُعدة بالكامل لتعمل كتطبيق هاتف ذكي أصلي (Native Mobile App) عبر طريقتين:

### 1️⃣ التثبيت كتطبيق ويب تقدمي (PWA - Progressive Web App) [فوري وبدون متاجر]:
- **على هواتف Android**:
  - بمجرد فتح الرابط في متصفح Chrome، يظهر زر **📲 تثبيت** أو رسالة "إضافة إلى الشاشة الرئيسية".
  - يتم تثبيت اللعبة فوراً كأيقونة تطبيق مستقل على شاشة الجوال وتعمل بملء الشاشة وبدون شريط عنوان المتصفح.
- **على هواتف iPhone (iOS Safari)**:
  - افتح الرابط في Safari، اضغط على زر المشاركة (Share ⎋)، ثم اختر **"إضافة إلى الشاشة الرئيسية ＋"**.
  - ستظهر أيقونة اللعبة الفاخرة وتفتح كتطبيق iOS كامل.

### 2️⃣ التغليف كتطبيق أندرويد أصلي (APK / AAB) أو iOS عبر Capacitor:
تم إرفاق ملف الإعداد `capacitor.config.json` جاهزاً:
```bash
# لإضافة منصة الأندرويد:
npm run cap:add:android

# لفتح المشروع في Android Studio واستخراج ملف APK مباشرة:
npm run cap:open:android
```

### ⚡ مميزات الجوال المدمجة:
1. **اهتزاز تفاعلي (Haptic Feedback)** عند النقر واختيار الحروف وزر التوقف.
2. **انتقال ذكي بلوحة المفاتيح**: عند كتابة إجابة وضغط "التالي (Next)" على الكيبورد، ينتقل المؤشر تلقائياً للتصنيف التالي.
3. **تثبيت زر «قِف! خَلّصت» أسفل الشاشة (Sticky Action Bar)** لسهولة وصول الإبهام إليه أثناء الكتابة.
4. **دعم النوتش والشاشات الحديثة (Safe Area Insets)**.
5. **تخزين مؤقت وسريع (Offline Caching via Service Worker)**.
